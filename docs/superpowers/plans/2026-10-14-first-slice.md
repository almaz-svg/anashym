# Первый рабочий срез — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Клиент входит, видит каталог, создаёт заказ с отсрочкой и видит резерв товара и кредитного лимита.

**Architecture:** React TypeScript обращается к Django REST Framework через /api/v1. PostgreSQL отвечает за транзакции, остатки и лимиты. Координатор владеет общими файлами; разработчики работают в отдельных каталогах.

**Tech Stack:** React, TypeScript, Vite, Django, DRF, PostgreSQL.

**Spec:** Исходное ТЗ версии 0.2 и docs/architecture.md; уточнения пользователя ниже имеют приоритет.

## Global Constraints

- Категория клиента обязательна: кофейня, магазин, ресторан/кафе, компания, частный покупатель, другое. Для другого требуется пояснение.
- Регистрация содержит описание деятельности и ожидаемые объём и частоту заказов.
- Оплаты и задолженности имеют отдельные разделы интерфейса.
- Отчёт по обороту доступен за любой период; автоматический недельный отчёт относится к этапу расчётов.
- Деньги — Decimal; задолженность возникает при передаче, а создание заказа резервирует лимит.
- Приватные сессии, CSRF, серверные области доступа, идемпотентность и PostgreSQL-проверки конкуренции обязательны.
- Только тестовые данные; ручная сверка Kaspi в будущем финансовом срезе.

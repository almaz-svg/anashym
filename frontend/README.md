# Клиент кондитерской

Требуется Node.js 22+ и запущенный Django на `127.0.0.1:8000`.

```sh
npm install
npm run dev
npm test
npm run build
```

Открыть http://localhost:5173. Vite проксирует `/api` и `/admin` в Django. Переменная `API_PROXY_TARGET` задаёт другой адрес (например `http://backend:8000` в Compose). Все запросы используют session cookie, CSRF и `/api/v1`.

Реализованы вход, регистрация с ожиданием одобрения, каталог по дате, порции, точка и время доставки, заказ с отсрочкой, повтор потерянного запроса с прежним ключом, детали и история заказов, серверные суммы задолженности. Оплаты и отчёты обозначены недоступными, пока не подключён соответствующий API. Клиент не рассчитывает долг и не подтверждает платёж локально.
